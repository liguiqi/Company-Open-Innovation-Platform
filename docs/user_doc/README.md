# User Docs Index

当前 `docs/user_doc/` 目录面向生产环境 `https://openinnovation.example.com`，用于给业务方、合作伙伴、评审员和管理员提供可直接执行的操作说明。

## 适用范围

1. 本目录默认以生产环境已部署能力为准。
2. 本机开发环境当前默认域名为 `https://innovation.example.com`。
3. 任何本机开发环境先行实现、但尚未部署到生产环境的能力，统一放到差异说明文档中单独标注。
4. 文档只描述当前仓库和已确认部署环境中可以被验证的页面、角色、流程和后台集合，不记录理想态需求。

## 文档清单

| 路径                                 | 说明                                                                   |
| ------------------------------------ | ---------------------------------------------------------------------- |
| `README.md`                          | 用户文档总索引                                                         |
| `production-user-guide.md`           | 生产环境用户操作手册，按公开站、注册登录、合作伙伴、评审员、管理员展开 |
| `local-vs-production-differences.md` | 本机开发环境与生产环境差异说明，重点覆盖中台需求发布和当前本地增强项   |

## 使用建议

1. 面向最终使用者、业务人员、验收人员时，优先阅读 `production-user-guide.md`。
2. 面向研发、实施、联调或上线评估时，同时阅读 `local-vs-production-differences.md`。
3. 若页面入口、角色权限、集合字段、附件上限或生产部署状态发生变化，必须同步更新本目录。
