# 架构文档

本目录描述的是“当前仓库 + 当前部署方式”的真实落地状态，重点回答三类问题：

1. 这个项目现在到底由哪些模块组成；
2. 数据、认证、文件和外部服务是怎么接起来的；
3. 线上实际如何启动、监听、反向代理和持久化。

## 文档清单

- `system-architecture.md`：系统边界、路由分组、集合模型、认证、数据访问方式、业务流与外部依赖
- `deployment-topology.md`：当前部署拓扑、端口、systemd / nginx / Docker 落地、目录与持久化方式

## 使用原则

- 只描述已经在仓库中实现、且可以从代码或配置中验证到的内容。
- 涉及密钥、密码、真实账号的部分只写变量名和运维要求，不写明文值。
- 如果架构变更影响路由、集合、认证、运行方式、端口或存储目录，必须同步更新这里。
