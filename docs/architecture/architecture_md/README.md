# 架构文档

当前架构文档面向正式版 `v1.0.0`，描述的是“当前仓库 + 当前部署方式 + 当前生产运维约束”的真实落地状态。

## 文档清单

- `system-architecture.md`：系统边界、路由、认证、集合模型、业务流与外部依赖
- `deployment-topology.md`：部署拓扑、端口、standalone 运行、systemd / nginx / Docker 关系

## 使用原则

1. 只写仓库和当前部署里已经实现、并可以验证到的内容。
2. 不在文档中记录明文密钥、账号密码和 token。
3. 任何影响认证、短信、邮件、部署、媒体目录或版本发布的变更，都应同步更新这里。
4. `.next/standalone/.env*` 属于当前架构的重要运行事实，不得忽略。
