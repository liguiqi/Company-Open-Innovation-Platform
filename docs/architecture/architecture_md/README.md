# 架构文档

当前架构文档面向仓库当前主线代码、当前本机开发部署方式，以及当前已知生产调试环境约束，更新时间为 `2026-04-30`。

## 文档清单

- `system-architecture.md`：系统定位、技术基线、路由分组、API、认证模型、集合模型、媒体归档和关键业务流
- `deployment-topology.md`：本机开发环境与生产调试环境的真实拓扑、端口、配置落点、构建链路与运行约束

## 使用原则

1. 只写当前仓库中已经落地并可从代码、构建产物或运行环境验证到的内容。
2. 前台公开站、认证中心、中台工作台和 Payload Admin 必须作为同一 Node 进程内的整体系来描述，不能误写成独立后端微服务。
3. 涉及主题系统、路由转场、品牌资源、附件目录、验证码链路、访问记录字段、评审时间线、部署端口或请求体大小限制的变更，都需要同步更新此目录。
4. `.next/standalone/.env*`、`media/` 目录和 Nginx `client_max_body_size` 都属于实际架构的一部分，文档中不能忽略。
