# 验收与测试清单

## 基础可用性

- 当前环境建议从 `http://127.0.0.1:3005` 开始验收；域名入口尚未完成正式切换
- 首页、需求大厅、生态伙伴、案例、合作流程页面可访问
- `/admin` 可打开 Payload Admin 登录页
- `/dashboard` 未登录时会跳转至 `/login`

## 认证链路

- 合作伙伴邮箱注册后收到验证邮件
- 点击验证链接后自动写入登录态
- 邮箱密码登录可进入 dashboard
- 手机号验证码发送成功；在缺少正式短信模板时，开发环境展示 mock 验证码
- 短信验证码登录后可进入 dashboard

## 业务链路

- 合作伙伴可提交新方案
- 管理员 / 评审员可查看全部方案
- 管理员 / 评审员可更新方案状态并填写评审意见
- 方案状态更新后触发邮件通知

## 演示账号

- 管理员：从 `.env.local` 的 `DEFAULT_ADMIN_*` 读取
- 评审员：从 `.env.local` 的 `DEFAULT_REVIEWER_*` 读取
- 合作伙伴：从 `.env.local` 的 `DEFAULT_PARTNER_*` 读取

## 已知限制

- `settings` 页面当前为只读
- 若阿里云短信模板未配置正式值，短信联调使用 mock 模式
- 若企业邮箱 SMTP 服务端临时重置连接，邮件通知会降级为 best-effort，不阻断注册、提案和状态流转主链路
- 截至 `2026-04-15`，当前阿里云短信账号查询结果为无可用签名、无可用模板，真实手机验证码暂不可用
