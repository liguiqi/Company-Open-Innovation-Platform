## 本轮确认的当前实现

- 仓库当前技术基线为 `Next.js 16.2.3 + Payload CMS 3.82.1 + React 19.2.4 + Tailwind CSS 4.1.14`
- 公开站、登录注册、工作台、Payload Admin 运行在同一 Node 进程内，不存在独立后端微服务
- 当前支持：
  - 邮箱 / 手机密码登录
  - 邮箱 / 短信验证码登录（仅已有账号可登录）
  - 基础信息 + 邮箱 / 手机任一验证的合作伙伴注册
  - 方案多附件上传、权限下载、评审时间线、个人设置自助更新
  - 管理后台 `users` 列表中的 `最后访问时间`
  - 伙伴目录分层展示与统一 SVG / Logo 资源管理
- 当前单文件附件业务限制已提升到 `100MB`
- 当前传输链路已同步：
  - `Next experimental.proxyClientMaxBodySize = 120mb`
  - `nginx client_max_body_size = 120M`
